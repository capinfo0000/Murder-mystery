# 紫苑館の秘密 — ゲーム設計資料

ランダム要素・キャラクター定義・凶器一覧をまとめた参照ドキュメント。

---

## 0. 物語のあらすじ・世界観設定

### 0-1. 舞台：紫苑館

明治期に建てられた純和洋折衷の大邸宅。神条財閥の総帥・**神条 源太郎**（当主）が居城とする山中の孤立した屋敷。

秋の台風が近づく夜、外部との連絡が断たれた状態で事件は起きる。

- 広大な敷地に書斎・書庫・絵画室・金庫室・温室・隠し部屋などが点在
- 館内には昔の増改築で生じた**秘密通路**が存在する（知る者は限られる）
- 最寄り駅まで車で1時間。嵐の夜は孤立無援

---

### 0-2. 被害者：神条 源太郎（当主）

神条財閥の創業家三代目。表向きは地方経済の重鎮として名声を誇るが、その実態は：

- 長男・薫に会社の巨額赤字を押しつけ、表向きの経営者に仕立てながら実権を握り続けた
- 主治医・白川に過去の医療ミスを握らせ、10年以上にわたって無報酬に近い形で縛り付けた
- 所蔵美術品の管理を名目に絵画修復家を館に招き、真贋鑑定の不正に利用していた
- メイド長の小夜を幼少期から引き取り、長年にわたり陰湿な支配と虐待を繰り返した
- 執事長・黒部を悪事の片棒担ぎとして使い、報酬として裏金を渡して口を塞いできた
- 次男・蓮を「役に立たない」と疎み、遺産廃嫡を突然宣告して館から追い出した
- 隠し子の存在を徹底的に隠蔽し、相続権を主張しようとする者を法的・社会的に抹殺しようとした

**源太郎は複数の人間から同時に狙われる「被害を受けるに足る悪人」として設計されている。**  
プレイヤー全員が嘘のアリバイを持ち、全員に動機があることが、この設計の核心。

---

### 0-3. 招集の夜——なぜ全員がここにいるか

源太郎は「遺産相続に関する重大な発表がある」と称し、関係者全員を紫苑館へ召集した。  
その真の意図は各人異なる目的で利用するため——だったが、結果的に「全員に動機と機会を与える夜」となった。

| キャラ | 表向きの来館理由 | 実際の目的 |
|---|---|---|
| A（薫） | 相続発表への出席（長男として当然） | 遺言書を改ざんし廃嫡を防ぐ |
| B（白川） | 当主の定期健康診断と投薬管理 | 医療ミスのカルテを書庫から回収・破棄 |
| C（氷室） | 所蔵絵画の修復作業（依頼済み） | 本物の名画を複製品にすり替える |
| D（小夜） | 屋敷の管理・来客接待 | 秘密通路で情報収集し、復讐の機会を窺う |
| E（黒部） | 屋敷全体の取り仕切り | 金庫室の裏金を持ち出す |
| F（蓮） | 廃嫡撤回の直訴（呼ばれていない） | 隠し部屋で毒草を管理する |
| G（麗華） | 突然現れた「故人の妻」を名乗る人物 | 権利証と出生書類を書斎から奪う |

---

### 0-4. 事件の発覚

深夜0時過ぎ、書斎で**神条 源太郎**が死体となって発見された。  
窓の外では嵐が激しさを増し、外部への通報は翌朝まで不可能。  
犯人はこの館の中にいる——あるいは、外部から侵入した者の犯行か。

プレイヤーたちは翌朝の警察到着までに、館内での討議・密談・証拠収集を通じて真相に迫らなければならない。

---

### 0-5. ゲームの核心構造

```
全員が「T2（殺害時刻）」に嘘のアリバイを持つ
         ↓
なぜなら全員がその時間に別の「秘密」のために動いていたから
         ↓
秘密を隠しながら他人を犯人と主張する討議
         ↓
投票：誰が当主を殺したか？  ／  外部犯（組織の殺し屋）？
```

- 犯人は「自分以外が怪しい」と見せかける偽装工作を行う
- 無実の人物も「秘密行動が露見すること」を恐れて嘘をつく
- 被害者（当主）自身も複数の悪事を抱えており、動機は全員にある

| パターン | カテゴリ | 死因の組み合わせ | 概要 |
|---|---|---|---|

## 2. キャラクター定義（固定）

動機・秘密行動はキャラクター固定。犯人に選ばれた場合のみ動機が参照される。

### 2-1. 設計方針：「過去の職業」による隠れたスキル

各キャラクターは **現在の役割** とは別に、過去の職業・経験に由来する **隠れたスキル** を持つ。
このスキルが犯行トリックの根拠となるが、背景文には直接書かず、**カードを通じて少しずつ示唆**する設計とする。

| 枠 | 現在の役割 | 過去の職業（隠れた出自） | 隠れたスキル | 犯行トリック |
|---|---|---|---|---|
| A | 長男 / 副社長 | 欧州オークションの真贋鑑定士（20代） | 筆跡鑑定・模倣 | ダイイングメッセージ改ざん・遺言書偽造 |
| B | 主治医 | 製薬研究所の研究員（医師免許取得前） | 処方外毒物・神経薬の知識 | 自然死偽装 + 別人へのフレームアップ |
| C | 絵画修復家 | 大道マジシャンのアシスタント（美術学生時代） | 変装・なりすまし・物品すり替え | 被害者に変装して死亡時刻をずらすアリバイ工作 |
| D | メイド長 | 錠前師の見習い（館に来る前の数年間） | あらゆる錠前の開閉・細工 | 外から施錠して密室を作る |
| E | 執事長 / 支配人 | 高級ホテルのチーフソムリエ（30代まで） | 飲料への微量物質の混入 | 宴席でワインに時間差毒を仕込み完璧なアリバイ |
| F | 庭師 / 次男 | 旅芸人の一座のマジシャン（放浪中の3年間） | 脱出術・ロープワーク | 密室からの脱出 / なりすましによる二重アリバイ |
| G | 謎の未亡人 | 詐欺師グループの構成員（若い頃） | 書類偽造・証拠でっち上げ | 遺書偽造で自殺偽装 + 別人への疑惑誘導 |

### 2-3. カードによる「過去職業ヒント」設計

過去の職業はハンドアウトに明記せず、**証拠カード・背景情報カード・目撃証言カード** に断片として散りばめる。
プレイヤーが複数のカードを組み合わせて初めて「あの人は元〇〇だ」と気づける設計。

#### ヒントカード例

| キャラ | カード種別 | カード文面の例 |
|---|---|---|
| A（薫） | 背景情報 | 「神条薫はかつてヨーロッパに5年滞在していた。帰国後も骨董品を見るとき特有の角度から光を当てて確認する癖がある」 |
| A（薫） | 物的証拠 | 「書斎のゴミ箱に、筆跡の練習跡らしき紙が複数枚捨ててあった」 |
| B（悟） | 背景情報 | 「白川医師が免許を取得したのは35歳のときだという。それ以前の10年間のキャリアは不明」 |
| B（悟） | 目撃証言 | 「白川は処方箋にない薬品名を流暢に並べていた。あれは臨床医の知識ではない」 |
| C（涼子） | 目撃証言 | 「氷室は酒の席で"昔は全然違う仕事をしていた"と笑いながら言っていた」 |
| C（涼子） | 物的証拠 | 「氷室の荷物の中に、絵画修復とは無関係の特殊メイク用品が入っていた」 |
| D（小夜） | 目撃証言 | 「小夜は古い南京錠を手に取り、一瞬眺めただけで音もなく開けてしまった」 |
| D（小夜） | 背景情報 | 「館に来る前の小夜の経歴を知る者は誰もいない。本人も絶対に語らない」 |
| E（黒部） | 目撃証言 | 「黒部はワインを一口含んだだけで産地と年代を当てた。あれはソムリエ試験の技術だ」 |
| E（黒部） | 背景情報 | 「黒部が神条家に仕える前、都内のどこかの高級ホテルにいたという噂がある」 |
| F（蓮） | 目撃証言 | 「蓮はロープの結び目を確かめるとき、庭師とは思えない鮮やかな手つきだった」 |
| F（蓮） | 背景情報 | 「神条蓮が家出していた数年間、一切の消息が途絶えていた。本人は"各地を転々とした"と言うだけだ」 |
| G（麗華） | 目撃証言 | 「綾小路麗華は自分の出身地について、今日と先日で微妙に違う話をしていた」 |
| G（麗華） | 物的証拠 | 「麗華の客間に、書類に使われた跡のある複数の異なるペンと印鑑が見つかった」 |

#### 配布ルール（案）
- **真のヒント**：上記カードは全て `isTrue: true` で山札に含める
- **ミスリードカード**：「薫は医学書を読んでいた（→Bへの疑惑を強める）」など偽の関連付けカードを混在させる
- 1ゲームで全カードを使い切らないため、ヒントが揃わないまま投票になるケースも発生する（緊張感の演出）

### 4-6. コナン式ゲーム構造との対応

#### コナン事件の定型フロー → 本ゲームとの対応

| コナンの構造 | 本ゲームの対応 |
|---|---|
| 全員が何らかの秘密を持つ | 全プレイヤーが T2 に秘密行動 |
| 被害者が道徳的に「悪人」 | 当主（被害者）は複数人から狙われる悪人背景 |
| 容疑者3人・全員に動機+アリバイの穴 | 全員が T2 の虚偽アリバイを持つ構造 |
| 物理証拠・科学トリックによる崩し | カードに証拠・アリバイカードを混在させ推理を促す |
| 犯人は必ず自白・経緯を語る | 真相タブで全事件の詳細を公開 |
| 犯人以外の秘密も暴かれる | ResultPage で全員の秘密行動を公開 |

#### コナン作品の重要ルール

- **血痕ルール**: 刺殺・撲殺では必ず犯人・凶器に血が付く
- **変装限界ルール**: 大人は子供に変装できない（身長差）
- **自白必須ルール**: 追い詰められた犯人は経緯を含め全て自白する
- **被害者悪人構造**: 被害者に道義的な非があるため犯人に感情移入しやすい

# 紫苑館の秘密 — 犯行動機・凶器一覧

## キャラクター別 犯行動機

動機はキャラクター固定（ゲームごとに変わらない）。犯人に選ばれた場合のみ参照される。

| 枠 | 名前 | 役職 | 犯行動機 | T2の秘密行動 |
|---|---|---|---|---|
| A | 神条 薫 | 長男 / 副社長 | 巨額赤字の発覚と廃嫡を防ぐため、真実を知る被害者を口封じした | 書斎から遺言書を盗み改ざんしようとしていた |
| B | 白川 悟 | 主治医 | 医療ミスの公表と免許剥奪を防ぐため、脅迫者である被害者を殺害した | 書庫から医療ミスが記録されたカルテを回収・破棄しようとしていた |
| C | 氷室 涼子 | 絵画修復家 | 名画のすり替えに気づいた被害者を証人として口封じした | 絵画室で本物の名画を複製品にすり替えていた |
| D | 小夜 | メイド長 | 長年自分を虐待し続けた被害者への積年の復讐を実行した | 秘密通路を使い客人の部屋を覗き見して情報収集していた |
| E | 黒部 達也 | 執事長 / 支配人 | 悪事の全容を暴露すると脅した被害者を口封じした | 金庫室から自分への手切れ金として預けられていた裏金を持ち出そうとしていた |
| F | 神条 蓮 | 庭師 / 次男 | 廃嫡・絶縁を宣告した被害者への怒りが頂点に達し殺害した | 隠し部屋に希少な毒草を持ち込み秘密裏に育てていた |
| G | 綾小路 麗華 | 謎の未亡人 | 自分の存在を隠蔽しようとした被害者を、正当な権利のために消した | 書斎から権利証と出生に関する書類を密かに奪おうとしていた |

## 動機×凶器の親和性（参考）

| 犯人 | 動機の性格 | 親和する凶器 |
|---|---|---|
| A（薫） | 計画的・口封じ | 毒系（時間差工作が可能） |
| B（悟） | 医師・冷静 | 睡眠薬・毒（医学的知識を活用） |
| C（涼子） | 機会的・証拠隠滅 | 手早い物理系 |
| D（小夜） | 積年の恨み・衝動 | 物理系（直接的） |
| E（黒部） | 緻密・組織的 | 毒系・環境系（痕跡を残さない） |
| F（蓮） | 衝動・怒り | 毒草エキス（秘密行動と一致） |
| G（麗華） | 必要に迫られた | 毒系（証拠を隠しやすい） |

> 現状、凶器はランダム選択のため上記の親和性は反映されていない。
> 将来的に動機×凶器の親和性でウェイト付けする拡張が可能。
